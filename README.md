# ES 112 · Introduction to Computing (2022)

Course website for ES 112 Introduction to Computing at IIT Gandhinagar, the four-week immersive edition of
November–December 2022: <https://nipunbatra.github.io/comp22/>

The site is a [Quarto](https://quarto.org) website in the same design as
[ES 667 Deep Learning](https://nipunbatra.github.io/dl-2026/). GitHub Pages serves this branch as it is, so the
site renders in place: every page's `.html` is committed next to its `.qmd`. After editing a page, run
`quarto render` and commit the result.

| File | Contents |
|---|---|
| `index.qmd` | Home: course facts, course record, module overview, questions, syllabus, lab sections |
| `schedule.qmd` | Lectures: every lecture with its slides, notes, recordings and notebooks |
| `assessment.qmd`, `_dates.qmd` | Dates, grading, worksheet and exam papers |
| `challenge.qmd` | Challenging questions |
| `lectures/`, `quizzes/`, `notebooks/` | Slides and notes, worksheet and exam papers, notebooks and code |
| `lectures/index.qmd`, `challenge/index.qmd` | Redirects from the old site's addresses |
| `styles.scss`, `course.scss`, `rail.html`, `course-theme.html`, `course-tools.html` | Shared theme |
